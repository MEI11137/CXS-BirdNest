# Changelog

All notable changes to the public CXS-BirdNest dataset release are documented in this file.

## [v2.1.0] - 2026-08-31

### Added

- Complete 5,404-image release: 4,692 training, 356 validation, and 356 test images.
- Directly pairable split-specific YOLO annotations in `labels-train.zip`, `labels-val.zip`, and `labels-test.zip`.
- Bilingual dataset documentation and machine-readable citation metadata.

### Dataset summary

- 5,404 image-label pairs.
- 6,148 bounding boxes for one category: class `0` (`bird nest`).
